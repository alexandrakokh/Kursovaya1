# Transaction Analyzer

Приложение для анализа транзакций из Excel-файла, генерации JSON-ответов для веб-страниц и отчётов.

## Возможности

- Главная страница: приветствие, траты по картам, топ-транзакции, курсы валют и акций.
- Страница События: расходы/поступления по категориям, переводы/наличные, диапазоны W/M/Y/ALL.
- Сервисы: инвесткопилка, анализ кешбэка, поиск по описанию, номерам, переводам физлицам.
- Отчёты: траты по категории, по дням недели, рабочие/выходные дни.
